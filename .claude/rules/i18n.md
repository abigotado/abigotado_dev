# Localization — arb sources

- `app_ru.arb`, `app_en.arb`, `app_es.arb` move in lockstep: a key added,
  changed, or removed in one is added, changed, or removed in all three in the
  same commit. `app_en.arb` is the template (`l10n.yaml`).
- The name is a localized key (Никита Коваленко ↔ Nikita Kovalenko), never a
  hardcoded string anywhere in the tree.
- arb is the source of truth. The generated output in `lib/src/l10n/gen/` is
  git-ignored — regenerate with `flutter gen-l10n`, never edit it.
- Translations carry meaning, not transliteration: each locale reads as native
  copy, and placeholders keep identical names and types across locales.
